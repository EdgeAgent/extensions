# Edge Agency Extensions

Product pages for the Edge Agency Chrome extension line — local-first agent
tooling for Chrome, built in London, Ontario.

**Live site:** https://edgeagent.github.io/extensions/

## The products

| Product | What it is | Status |
| --- | --- | --- |
| **Conductor** | AI browser agent & MCP tools — the suite everything is folding into | Live on the Chrome Web Store · v1.3.0 in review |
| **Agent Wallet** | Capped spending for AI agents — the specialist guard | In Chrome Web Store review |
| **API Lens** | Reverse API engineer — capture a site's API, export OpenAPI + typed clients | Live on the Chrome Web Store · v1.1.1 in review |
| **Agent Flight Recorder** | Session timeline, one-click undo, receipts — joining Conductor as the Journal module in v1.4 | Module in build |
| **Mesh Mode** | Conductor's local agent-mesh node — verifiable handoffs between your own machines | Arriving in Conductor v2.0 |

## Conductor suite roadmap

v1.3 Takeover Mode → v1.4 Journal (Flight Recorder inside) → v1.5 Lens module →
v1.6 Wallet guard → v2.0 Mesh Mode. One product, one listing, modules added by
update — every module local-first, opt-in permissions, receipts for agent actions.
