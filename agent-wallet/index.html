Agent Wallet

Agent Spending Guard

A spending guard for AI agents — per-transaction and daily caps, an approval line, and a full receipt trail. Never holds your keys.

In Chrome Web Store review
Pro $9/mo planned

What it does

  • Per-transaction cap. Set the most an agent may spend in a single transaction; anything above it cannot proceed.
  • Daily cap. A hard ceiling on total agent spending per day, enforced before any payment is attempted.
  • Approval line. Purchases above your chosen threshold stop and wait for your explicit approval.
  • Full receipt trail. Every approved and blocked spend is recorded, so agent spending is auditable end to end.
  • Never holds your keys. Agent Wallet guards spending — it does not store your payment keys or credentials.
  • Agent identity. Spending rules can be set per agent, so each agent operates inside its own limits.

Privacy

Local only. Agent Wallet runs entirely on your device and stores no keys — your credentials never pass through it.
