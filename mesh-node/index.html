Your browser joins your local agent mesh — verifiable handoffs, SlimDOM page reads, approval-gated actions, receipts for everything. No cloud.

Pro $3.99/mo

What it does

  • A node in your local mesh. The browser enrolls as a node in the agent mesh running on your own machines — discovered locally, synced peer-to-peer, with no cloud in the loop.
  • Verifiable handoffs. Work passed to and from the browser is written as a two-entry proof in hash-chained receipt ledgers, so a handoff can be audited from both sides.
  • SlimDOM page reads. Pages are returned to mesh agents in SlimDOM form — semantic, stripped of styling and script noise, ready for an agent to work with.
  • Approval-gated actions. Consequential actions — submits, sends, purchases, deletes — never run on a mesh instruction alone; they stop at an inline approval drawer first.
  • Scoped capability tokens. The browser node acts only under tokens scoped to a specific template and a specific origin.
  • Receipts for everything. Every invocation, approval, and result is recorded in the browser node's own receipt chain.

Privacy

Local only. The node acts inside your logged-in browser session but never exports it — session cookies and tokens never leave the browser and never enter mesh state.
